01 / OVERVIEW

先看清这个项目在做什么

不是一次湖泊水位监测，而是一套“水位情景—生态响应—阈值调控”的耦合研究。研究对象从湖面一直延伸到鱼和鸟。

01

委托与定位

对应商务技术文件第 91–93 页，由中国科学院青藏高原研究所负责。核心任务是解释水位持续上升引发的生态格局与系统稳定性变化。

任务书 · 项目申请书

02

核心科学问题

水位变化如何重构“水—草—鱼—鸟”多营养级共生网络，并改变生态系统功能？哪里是敏感区，哪里是关键节点，哪里是临界水位？

项目申请书 · 考核指标

两个同时发生的变量

水位持续上升改变空间与淹没范围；湖水盐度持续下降改变生理过程与群落结构。两者叠加，才解释得通鱼群与鸟群的变化。

主线只有一条：水位变化 → 生境格局重构 → 植被 / 鱼类 / 鸟类响应 → 多营养级网络重组 → 系统稳定性变化。

7.1

湖岸区生态格局

水位抬升对湖岸格局的重塑；淹没侵蚀对湖岸功能的影响。

7.2

关键物种栖息地

裸鲤产卵场向河口迁移；盐度下降与早期资源补充；鸟类繁殖岛与陆生物种栖息地。

7.3

共生关系与稳定性

网络结构的多层级影响、不同水位扰动下的抗风险能力、水位—结构功能耦合调控。

研究对象 湖泊水体 湖滨湿地 高寒草地 裸鲤 水鸟 普氏原羚 浮游生物

R5

“水—草—鱼—鸟”统计网络

AICc + LOOCV
  • 2020–2025：裸鲤资源量 ~ 水位 R² = 0.912；水鸟 ~ 裸鲤 + 浮游动物 0.850；普氏原羚 ~ 可食生物量 + 水位 0.650。
  • 2014–2023 复核：鱼 ~ 水位 0.932；兽 ~ 可食 + 水位 0.968；鸟 ~ 鱼 0.564。
  • 藻类环节最弱：Chl-a ~ 水位 R² = 0.024；PP 加入盐度后 R² 升至 0.27，但 LOOCV 误差反而变大，判断为过拟合。
  • 结论：鱼—水位与兽—草两段最稳；水—藻第一环尚未成立。

来源：执行 / 生态网络模型（水藻草鱼鸟兽）.docx

哪些数字可以直接引用？

DEM 偏差、景观指数方向、生境质量均值、WCI 连通面积、网络 R²、淹没与刚毛藻比例、水质统计量均来自工作文档中的表格或图件。带“示意”字样的图（如首页曲线）不是计算结果；进度百分比是编者判断。

为什么反复强调“未闭环”？

模型集的七个模块共享水位情景。情景数值尚未填写，EFI 就无法形成连续曲线，阈值、ENSI/NVI 与三维表达也无法可靠生成。当前结果足以支撑单环节论证，但不足以支撑“安全水位”结论。

与已有“研究路线图谱”网站是什么关系？

本站是独立项目页面，聚焦“青海湖流域生态系统结构与功能响应”这一课题；另一个站点解读的是《青海湖高原湖泊湿地演变趋势及应对措施》报告。两者资料与对象不同，不互相替代。

一句话总结

数据已经够用，模型还差“情景”这一脚。

项目最扎实的部分是空间底图与单环节证据；最薄弱的部分是把它们串成一条可调参、可复现的响应曲线。

建议的下一步

  1. 先冻结 S00–S06 水位情景与统一空间底图。
  2. 用情景批量生成 WCI、S、H，拟合 EFI 曲线。
  3. 在情景网络上计算 ENSI / NVI，确定关键节点。
  4. 补裸鲤、水鸟 HSI 与 CRI 指标，再做敏感性分析。
  5. 用 FPP / FCCI 补鱼类环境容纳力核算，支撑放流分区。
  6. 最后启动三维表达与三类专题图集。
